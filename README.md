# astrbot_plugin_outfit_lookup

剑网3外观截图识别插件：发送外观截图，返回外观名称。

基于本地部署的识别服务（视觉三模型融合 + 精排），支持四体型（萝莉/正太/成女/成男）成衣正面截图。

## 使用

```
外观识别 [萝莉|正太|成女|成男] + 图片
```

- 在发送命令的**同一消息**里附上一张游戏外观截图（近景、半身最佳）
- 体型参数可选：不传时自动判断（需配置支持图片的默认对话模型）
- 返回外观名称、匹配度和候选列表

## 配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `api_base_url` | 识图 API 地址 | `http://192.168.1.4:8390` |
| `enable_llm_body_detect` | 未指定体型时用默认对话模型自动判断 | `true` |
| `top_k` | 返回候选数量 | `5` |

> 多模态体型判断读取 astrbot 中用户已配置的默认对话模型，模型需支持图片输入；未配置或判断失败时自动退回全量检索。

## 部署

将本目录放入 astrbot 的 `data/plugins/` 下，重载插件即可。

识别服务（jx3_outfit_lookup）需另行部署，监听 `0.0.0.0:8390`。
